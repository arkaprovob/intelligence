# streamlining deployment with git broker
introducing git broker in spaship for streamlined git-based deployment, enhancing developer experience. simplified deployment process with one-time interaction for seamless app deployment from git. we'll available this feature in the upcoming release, here is an overview of the git broker.
## overview
previously, we've introduced the build and deployment directly from the source in workflow 3.0 for all containerized applications, specifically from git. now we're taking this step further with the idea of the git broker application. the git broker aims to enhance developer experiences by simplifying deployment processes and reducing operational steps.
## the vision behind git broker
the git broker application is conceived to offer a seamless experience to developers, performing direct deployment of applications from git. by utilizing this application, developers only need to interact once to initiate the deployment process (zero interaction for the preview environment), minimizing the effort and time traditionally required for deployment.
![git broker](./images/git_broker1.png)
## key features of git broker
1. **auto ephemeral environment creation:** one of the pivotal features of the git broker is the automatic creation of ephemeral environments. upon a developer raising a pull or merge request, spaship will promptly generate an ephemeral environment from the specific pull/merge request. this ensures an efficient and isolated testing environment for the requested changes.
2. **deploy using comments:** with git broker, deploying applications has been simplified further. developers can now deploy their applications directly by mentioning the target environment in the comments of the associated commit. this feature eliminates the need to repeatedly open spaship manager for redeployment, streamlining the development process.
3. **seamless integration:** git broker seamlessly integrates with popular version control platforms like github and gitlab. the integration process is straightforward and only requires a one-time setup. for github, developers need to integrate the spaship github application to use git broker, while for gitlab, a webhook integration available in the spaship manager property section.
the git broker application is another step forward in making it easier to deploy things in the spaship system. it makes things simpler and faster, so developers can concentrate more on their main work and speed up how quickly they create things. as spaship keeps getting better, the git broker application shows how committed we are to making things easier for developers and improving the way we work.
